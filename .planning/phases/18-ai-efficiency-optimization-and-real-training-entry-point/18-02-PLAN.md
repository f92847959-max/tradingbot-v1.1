<objective>
Wave 2: raise the real-training data floor from TRAIN-07's 6 months to 48 months, and add `--max-history` semantics (always fetch max available, cache-and-extend never re-download). Smoke / unit-test paths keep the legacy 6-month floor.

This wave is the data-pipeline upgrade — it does NOT touch model architecture, walk-forward windowing, or features. Walk-forward window count auto-scales because more data → more windows; that's free.
</objective>

<threat_model>
- T-18-04: A user runs real training against a short dataset and gets a misleading model with no warning (Phase 12.7 preflight only enforced 6 months).
  mitigation: 48-month floor at the preflight layer; hard error names the gap; only --smoke and explicit --allow-short-data bypass.
- T-18-05: --max-history re-fetches months of cached data, hammering Capital.com rate limits.
  mitigation: cache-and-extend resolver computes (cached_range_end, requested_range_end) delta and only fetches the gap.
- T-18-06: TRAIN-07 unit tests start failing because they pass 6 months of data.
  mitigation: tests use DEFAULT_MIN_MONTHS_SMOKE (6 months) explicitly; production paths use DEFAULT_MIN_MONTHS_PROD (48 months).
</threat_model>

    3. Add helper `def fetch_with_cache(symbol: str, timeframe: str, *, max_history: bool, years_cap: int | None, output_dir: Path) -> Path:`
       Semantics:
       - Determine `request_end = datetime.now(UTC)`; `request_start = request_end - relativedelta(years=years_cap)` if years_cap else `MIN_DATETIME` (Capital.com's documented earliest available).
       - If a cached CSV exists, compute its range. Fetch ONLY `(cached_last_ts, request_end]` if `cached_last_ts < request_end` AND ONLY `[request_start, cached_first_ts)` if `cached_first_ts > request_start`. Append to existing CSV, sort by timestamp, dedupe.
       - If no cache, fetch the full requested range.
       - Atomic write: write to `{output_dir}/{symbol}_{timeframe}.csv.tmp` then rename.
    4. Wire `--max-history` to call `fetch_with_cache(..., max_history=True, years_cap=args.years if args.years > 0 else None, ...)` for each requested timeframe.
    5. Backward compat: when `--max-history` is absent, behavior is unchanged from today.
