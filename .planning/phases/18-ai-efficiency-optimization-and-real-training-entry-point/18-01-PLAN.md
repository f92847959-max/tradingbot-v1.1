<task type="auto">
  <name>Task 2: Replace main.py with argparse dispatcher</name>
  <files>main.py</files>
  <read_first>

    - scripts/run_backtest.py

  <action>
    Rewrite main.py as a thin dispatcher (target: under 200 lines):

    1. Keep the initial `os.chdir(os.path.dirname(os.path.abspath(__file__)))` block (already present).
    2. Replace the `if __name__ == "__main__": asyncio.run(main())` block with:
       - `parser = argparse.ArgumentParser(prog="goldbot", description="GoldBot 2 unified entry")`
       - `parser.add_argument("--profile", action="store_true", help="Enable cProfile output to logs/profiling/")`
       - `subparsers = parser.add_subparsers(dest="mode")`
       - `train_parser = subparsers.add_parser("train")` — leave its arguments empty for now; Wave 2 fills it via `add_train_args(train_parser)` imported from start_ai_training.
       - `backtest_parser = subparsers.add_parser("backtest")` — same passthrough pattern for `scripts/run_backtest.py`.
       - `live_parser = subparsers.add_parser("live")` — no args today.
    3. Dispatch:
       - If `args.mode == "train"` → `from start_ai_training import run_train; sys.exit(run_train(remaining_argv))`
       - If `args.mode == "backtest"` → `from scripts.run_backtest import run_backtest; sys.exit(run_backtest(remaining_argv))`
       - If `args.mode == "live"` OR `args.mode is None` → call existing `run_live` via `asyncio.run(run_live(get_settings()))`
       - If `args.profile` is set, wrap the dispatched call in `profile_call(...)` from `scripts.profiling_harness` (created in Task 4)
    4. Backward compatibility: bare `python main.py` (no subcommand) must produce the same boot sequence as today (live mode).

    Use `parse_known_args()` so unknown args after `--mode train` pass through to start_ai_training.py untouched.
  </action>
