## Phase Boundary

**Goal (ROADMAP):** Dow Theory confirms or contradicts the Elliott-Wave master count via trend phases, high/low structure, volume/order-flow context, and multi-timeframe confirmation.

**In scope:**
- A Dow Theory trend classifier: primary trend (UP / DOWN / RANGE) + secondary (counter-move) from swing structure (HH/HL vs LH/LL).
- Volume / order-flow confirmation of the trend (reuse Phase 13 `flow_*` features / OHLCV volume).
- Multi-timeframe confirmation (primary TF vs a higher TF must agree).
- An agreement check against the Elliott Wave **primary count** (confirms vs contradicts).
- Exposure as causal ML features (mirroring `elliott_wave_features`) and an opt-in signal-context layer.

**Out of scope:** independent Dow-based trade entries; new data sources; model retraining; injecting Dow text into MiroFish prompts (numeric features only this phase — avoids new prompt-injection surface).

<decisions>
## Implementation Decisions (Claude's discretion — auto-decided)

1. **Swing source:** Reuse `ai_engine.elliott_wave.detector.WaveDetector.detect_swings` (single source of truth for pivots; no second swing algorithm).
2. **Primary trend:** UP when the last swing highs are rising AND swing lows are rising (HH + HL); DOWN when LH + LL; otherwise RANGE. Evaluated over the most recent few pivots; never raises (RANGE on insufficient data).
3. **Secondary trend:** the latest counter-move against the primary, for context only (lightweight).
4. **Volume/order-flow confirmation:** trend "confirmed" when volume/flow supports it (heavier participation on trend legs). Prefer Phase 13 `flow_*` features when present, fall back to OHLCV `volume`; graceful "unknown" when neither is available.
5. **Multi-timeframe confirmation:** compare the primary-timeframe trend with a higher timeframe (5m vs 15m); confirmed when directions agree. Reuse the MTF dict already fetched in the signal path.
6. **EW agreement:** derive an EW directional bias from the primary count (`ew_is_motive` + wave direction); Dow **confirms** when its primary-trend direction matches the EW bias, **contradicts** when opposite, **neutral** when either side has no read.
7. **Output surface (mirror EW 14-03):**
   - ML features in `ai_engine/features/dow_theory_features.py`: `dow_trend` (0=down,1=range,2=up), `dow_confirms_ew` (0/1), `dow_volume_confirmed` (0/1), `dow_mtf_confirmed` (0/1); registered in `FeatureEngineer`.
   - Optional signal layer governed by `settings.dow_filter_enabled` (default **False**): when the Dow primary trend contradicts a directional signal, down-rank/annotate it (BUY-only veto pattern, same shape as the EW filter).
8. **Governance & safety:** everything opt-in, default off; pure-decision core split from I/O for testability; functions never raise (zeros/neutral on failure); all files < 500 lines.
</decisions>
